# Nama Invaders

Alien invaders are trying to breach into my station! It is up to you to destroy them before the time runs out.

## Controls

- You will be prompted to choose the number of enemies (5 is the limit): enter the number in the console.
- WASD to move
- SPACE to shoot

## How To Win

- Defeat all enemies within the time constraint
- Hitting an enemy grants 10 base points each
- You end score will be increased depending how fast your defeat the enemeies
- Your time constraint will depend on the number of enemies

## Developer's Note

This is my first ever game built with Pygame. Therefore it is pretty basic. Also I opted out of using sprites and wanted to attempt to create this game without them. I instead used the draw module in Pygame.
